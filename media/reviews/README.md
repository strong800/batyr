# Сюда кладутся видеоотзывы

Положите в эту папку файлы роликов и выполните в корне проекта:

```bash
npm run reviews:import
```

## Что происходит с файлами

1. Каждый ролик сжимается до веб-версии `mp4` шириной не больше 720 px.
2. Снимается постер-кадр со второй секунды.
3. Оригинал копируется в `public/uploads/originals/reviews/` — веб-версия сжата с потерями, исходник остаётся нетронутым.
4. В базе создаётся отзыв, к нему привязывается видео, и он сразу появляется в блоке «Отзывы» на главной.

## Что важно знать

**Имена файлов становятся адресами.** `Отзыв Марии.MOV` превратится в `otzyv-marii.mp4`. Кириллица транслитерируется, пробелы заменяются дефисами.

**Имя файла — это ключ записи.** Повторный запуск команды не создаёт дубликат: файл с тем же именем обновит уже существующий отзыв. А вот переименование файла заведёт новый отзыв, старый останется в базе — его нужно будет удалить в админке.

**Подписи скрипт не выдумывает.** У нового отзыва будет нейтральное имя «Заказчик». Настоящее имя, город и текст впишите в админке: `/admin/reviews`.

**Форматы:** `.mp4`, `.mov`, `.m4v`, `.avi`, `.mkv`, `.webm`. Вертикальная съёмка с телефона — нормально, плеер показывает ролики в родном формате.

**Размер исходников не важен.** Ролик на 180 МБ сожмётся до нескольких мегабайт. Пять роликов на 292 МБ ужались до 46 МБ.

## Если нужно пересжать уже обработанное

```bash
npm run reviews:import -- --force
```

## Если ролики лежат в другом месте

Путь переопределяется переменной окружения `BATYR_REVIEWS_DIR` — тогда копировать файлы сюда не нужно.
