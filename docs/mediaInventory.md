## 5. Техническое состояние медиа

- EXIF-тега ориентации нет ни у одного файла → перевёрнутых фото не будет.
- Все фото 2048×2560 (4:5), кроме брендового слайда 2560×1440 (16:9). Это Telegram-компрессия: 300–1080 КБ на кадр, видны артефакты в небе и градиентах. Апскейлить бессмысленно, для сетки хватает.
- 4:5 у всех карточек — для широких hero-блоков и горизонтальных превью запаса по высоте нет. Сетку каталога проектирую под вертикальный формат 4:5, это как раз играет на «журнальный» вид.
- Плашка «дома из профилированного бруса / собственное производство» есть почти на каждом кадре — на сайте это будет читаться как водяной знак чужой площадки.
